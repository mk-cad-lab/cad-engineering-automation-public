# CAD Engineering Automation

CAD・設計データ管理業務の改善と、それを支える開発・運用基盤の整備に取り組んでいます。

本サイトでは、プロジェクトの目的、現在の開発状況、今後の計画を公開しています。

## プロジェクトの目的

CAD Engineering Automationは、Autodesk Inventorを中心に、AutoCAD MechanicalやAutodesk Vault Professionalを含むCAD・設計データ管理業務の改善を目的とするプロジェクトです。

定型的な操作や入力、確認作業の負担を減らし、誤操作や入力漏れを防ぐことで、設計者が本来注力すべき設計・技術検討に集中できる環境を目指します。これにより、設計品質と業務効率の向上につなげます。

定型作業の標準化・自動化に加え、日常的なCAD操作の利便性を高める機能や、設計情報の入力・確認、設計データの管理を支援する機能などを整備します。取り組む機能は、業務上の必要性や改善効果を踏まえて選定します。

機能の開発にあたっては、設計者が担うべき専門的な判断や必要な確認を残し、判断に必要な情報を分かりやすく提供します。また、問題が発生した場合にも、その状況を把握し、適切に対応できるよう支援します。

開発した機能を安全かつ継続的に利用できるよう、導入・更新・保守・復旧までを含めた仕組みを整備します。既存の設計データや利用環境を保護し、通常のCAD利用者が個別に配付・更新作業を行う必要のない運用を目指します。

開発環境の再現性を確保し、開発から検証・配付までを一貫して行える基盤を整備します。特定の開発端末や担当者に過度に依存せず、環境の再構築や担当者の交代があっても、開発・検証・保守を継続できる状態を目指します。

## 現在の取り組み

現在は、業務機能の開発を継続的に進めるための、開発・運用基盤の整備に重点を置いています。

個別の機能を開発するだけでなく、開発環境の構築から検証、利用環境への提供、保守・復旧までを一貫して扱える状態を目指しています。

主な取り組みは次のとおりです。

### 開発環境の整備と再現性の確保

開発に必要なツール、依存関係、構成を整理し、特定の端末でしか開発できない状態を避けるための基盤を整備しています。

開発端末の交換や担当者の交代があっても、必要な環境を再構築し、開発・検証を継続できることを重視しています。

### 開発・検証・Release管理の整備

ソースコードの管理、Build、Test、Releaseまでのつながりを整理し、開発した機能の内容や検証状況を追跡できる仕組みを整備しています。

実装が完了したことと、実際のCAD環境で正しく動作することを区別し、対象となる環境での検証を段階的に進めています。

### 導入・更新・復旧の仕組み

CAD利用者が導入や更新のための配付作業を個別に行う必要のない運用を目指しています。

また、機能の更新や障害への対応において、既存の設計データや利用環境を保護しながら、安全に利用を継続・復旧できる仕組みを検討・検証しています。

## 開発状況

| プロジェクトの基本方針・管理基盤 | 基本整備完了 |
| 開発環境・Build・Test | 整備・検証中 |
| CAD製品上での機能検証 | 一部の動作を確認済み |
| Release・導入・更新・復旧 | 一連の仕組みの成立を検証中 |

プロジェクトを進めるための基本方針や管理基盤の整備は完了し、現在は実際の開発・検証を通じて、技術的な仕組みの成立を確認しています。

初期の検証対象にはInventorのドキュメント属性検証を採用しており、基本機能の実装と一部の動作確認が進んでいます。

一方、機能の導入・更新・復旧を含む一連の仕組みは、まだ成立確認を完了していません。現在の成果は主に開発・非本番環境での限定的な検証結果であり、本番環境への適用や業務上の受入が完了したことを意味しません。

## 今後のロードマップ

### 1. 開発・検証基盤の確立

**現在の重点**

開発環境の再現性、Build・Test、CAD製品との接続など、業務機能の開発と検証を支える基盤を整備します。

実際の開発・検証を通じて、技術的な成立条件を確認し、継続的に開発できる環境を整えます。

### 2. 安全な提供・運用の実現

**初期成果に向けた目標**

選定した業務機能について、開発・検証からRelease、導入・更新・復旧までを一貫して成立させます。

まずは非本番環境で必要な動作と安全性を確認し、業務上の評価や適用条件を踏まえて、次の展開を判断します。

### 3. 業務機能の拡充と継続的な改善

**今後の展開**

整備した開発・運用基盤を活用し、CAD・設計データ管理業務の改善を進めます。

対象とする製品や機能は、業務上の効果、技術的な実現性、安全性、運用負担を考慮して選定します。

具体的な実施時期や適用範囲は、各段階の成果と検証結果に応じて判断します。

## このサイトについて

本サイトは、CAD Engineering Automationの概要や開発状況など、外部公開向けに選定した情報を提供しています。

ソースコード、内部向けの技術資料、詳細な作業・検証記録などの開発資産は、本サイトとは分離して管理しています。
